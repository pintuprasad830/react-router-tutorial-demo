# React Router Tutorial Demo

A simple React application demonstrating routing using React Router DOM.

## Features

* Home Page Navigation
* Java Tutorial Page
* React Tutorial Page
* Weather Dashboard Route
* 404 Page Not Found Handling
* Navigation using Link Component

## Technologies Used

* React JS
* React Router DOM
* JavaScript
* Bootstrap
* Vite

## Concepts Used

* BrowserRouter
* Routes
* Route
* Link
* Component Navigation
* Dynamic Routing
